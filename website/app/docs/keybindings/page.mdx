# Key bindings

<Media src="help.png" alt="The help screen" caption="? shows them all." />

| Keys | Does |
| --- | --- |
| <Kbd>k</Kbd> <Kbd>j</Kbd> / arrows | move up and down |
| <Kbd>ctrl+u</Kbd> <Kbd>ctrl+d</Kbd> / page keys | page up and down |
| <Kbd>g</Kbd> <Kbd>G</Kbd> | first and last row |
| <Kbd>H</Kbd> <Kbd>L</Kbd> / <Kbd>ctrl+←</Kbd> <Kbd>ctrl+→</Kbd> | move focus between panels |
| <Kbd>tab</Kbd> <Kbd>shift+tab</Kbd> | next and previous tab |
| <Kbd>n</Kbd> / <Kbd>w</Kbd> | open a tab / close it |
| <Kbd>enter</Kbd> | open; a row's actions; write in a room; send |
| <Kbd>space</Kbd> <Kbd>a</Kbd> <Kbd>A</Kbd> | mark a row, mark all, clear marks |
| <Kbd>/</Kbd> | filter rows |
| <Kbd>s</Kbd> | change the sort |
| <Kbd>r</Kbd> | reload the section |
| <Kbd>:</Kbd> | command prompt |
| <Kbd>?</Kbd> | help |
| <Kbd>esc</Kbd> | dismiss what is open |
| <Kbd>q</Kbd> / <Kbd>ctrl+c</Kbd> | quit, after asking / at once |
